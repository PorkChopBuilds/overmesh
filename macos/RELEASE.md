Click-to-open OverMesh for Intel Macs, with a purple-and-green Joker theme.

- Bundles Python and radio dependencies; no Terminal setup.
- Opens the local dashboard in your default browser, replacing the embedded window startup path associated with the crash report.
- Repeated launches reopen the existing dashboard. Use the dashboard power button to restart or shut down. Closing a browser tab does not stop the service.
- Preserves settings and history in ~/Library/Application Support/OverMesh.
- Purple #AB5DEE, lilac #BE80FF, green #1DDD33, deep green #1DA11F, neutral #C5C5C5.

Download the ZIP, unzip it, and move OverMesh.app into Applications. This community build is ad-hoc signed, not Apple notarized.

Validation: packaged backend, startup, duplicate launch, restart, shutdown, and 37 focused upstream tests passed locally on Intel macOS 26.7.1. Dashboard appearance checked in a browser. Radio hardware and full Finder-to-browser launch are not yet verified. GitHub also builds and tests the downloadable app before publishing.
